# Air Canada Flight Management Computer

## Welcome aboard!

This is the **Flight Management Computer** designed for pilots of **Air Canada Virtual Airline**. It’s built to give pilots a smooth and immersive experience. *Ding dong!* Please fasten your seatbelts and get ready for takeoff.

Special thanks to **ButterMasterr (daproatgames)** and **Alphonse Bertillon** (Former Virtual Airline CEO) for the original idea and inspiration.

---

## ⚠️ Note on Future Plans

This Flight Management Computer is currently fully functional, but it’s likely to be replaced by a new and improved version down the line, but not anytime soon though, so enjoy this one while it lasts!
